# Changelog

## [1.0.8] — 2026-09-28

**Requires Unity 6000.3 LTS+.** Menu: Window › Panchuel › BetterTabs.

### Added

- Sub-assets (sprites, meshes, clips…) in both trees.
- Copy, cut, paste and duplicate (Ctrl+C/X/V/D).
- Drop Hierarchy objects on a folder to create prefabs.
- Apply / Revert for import settings.
- How to Use and Settings inside the window (? and gear, bottom right).
- Prefab tabs: Save and Ctrl+S; also saved when leaving or closing the tab.

### Changed

- Double-click opens a file; folders still open as tabs.
- One selection mark, mirroring Unity's selection in both panels.
- Focus in Scene only shows when the object's scene is open.

### Fixed

- Tabs keep their expanded folders.
- Dropping on the empty panel creates a tab.
- Entering Play Mode no longer rewrites open prefabs.
- Drag and recompile console errors.
